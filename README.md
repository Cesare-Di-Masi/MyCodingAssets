# MyCodingAssets

Archivio di esercizi scolastici, progetti personali e materiali di sviluppo.

## Navigazione

- [`Docs/RepoStructure/`](Docs/RepoStructure/) contiene lo strumento e i report aggiornabili per albero e conteggi.
- [`School/`](School/) raccoglie i materiali scolastici per linguaggio e contesto.
- [`Personal/`](Personal/) raccoglie i progetti personali per linguaggio.
- `C#/` conserva asset e strumenti .NET condivisi.
- [`School/Other/`](School/Other/) raccoglie esercizi e laboratori scolastici multipiattaforma.
- [`Archive/Other/`](Archive/Other/) conserva strumenti ed esperimenti misti non riclassificati.
- [`Docs/`](Docs/) contiene documentazione e mappe del repository.
- [`REPO/`](REPO/) è un'applicazione autonoma per esplorare repository Git.

La riorganizzazione e la mappa completa dei percorsi precedenti sono documentate in [`Docs/Repository-Organization.md`](Docs/Repository-Organization.md) e [`Docs/Repository-File-Moves.tsv`](Docs/Repository-File-Moves.tsv).

Il README precedente conteneva il titolo `MyCodingAsset`; il testo è registrato nella documentazione di riorganizzazione.

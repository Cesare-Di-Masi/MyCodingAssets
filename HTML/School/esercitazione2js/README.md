# Esercitazione 2 (AJAX)
Creare un sito web completo in grado di effettuare delle richieste a un server che fornisca delle Web API e si aggiorni dinamicamente in base alla risposta, siete liberi di scegliere a quale API pubblica mandare la richiesta, una lista di possibili API pubbliche la trovate qui: https://free-apis.github.io/#/browse, usatene una che non richiede autenticazione o chiavi varie.
## Funzionalità del sito
- Pagine HTML + CSS + JS, se conoscete delle librerie grafiche che volete usare (es. Bootstrap o Tailwind) potete farlo anche se non le abbiamo ancora viste.
- Almeno 2 campi di input per la ricerca o filtraggio delle informazioni
- Una sezione apposita in cui mostrate (formattato bene) le informazioni fornitevi dal server a cui mandate la richiesta
